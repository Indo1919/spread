# Project 2: *Spread*

Demo/template for our [second projects](https://typography-interaction-2627.github.io/project/2/).

> **Students will now work together—with a new reading from those selected by the class in [*Manuscript*](https://typography-interaction-2627.github.io/project/1/)—to express a text deliberately and consistently across devices.**
>
> The goal of this project is twofold: both an effective *collaboration* between partners and also a successful, *responsive* design. Each duo will sketch cooperatively and then implement a joint execution together, via pair programming. The final web page will be responsive for mobile, desktop, and print layouts.

## The Reading and Our Response

Richard Hollis main argument is that the typographic grid came from rectangular pieces of metal type with the main objective of having information be organized within it. We chose to embody his perspective and design with a grid, so the general form of the page can be a visual discription instead of just holding words. The layout is a grid of colored blocks being seperated by a thin black line representing metal type being seperated by strips of lead.

## Color

The palette is made of up orange, red, and blue, with black for the grid lines and cream for the sections that have text. The colored blocks and black lines come from Mondrians paintings which Hollis includes in his text. We intentionally kept this palette limited because Hollis argued that the grids intention is to reduce the number of choices for people so we tried to embody this argument with intent in our choices. Every one of the sections has its own heading color so that readers can identify when they are in a different section.

## Type

We used Syne for the title and headings to give the title a strong presence as well as match the modernist feel that this article and styling has. Space Grotesk was used for the body text as it is clean and easy to read as well as matching with Syne and following all of our design intentions. The title is the biggest moment on the page and it was intentionally made to scale with different screen sizes in order to make sure that decision follows no matter what size screen the user has.

## Layout of the Grid

We chose to number and break this long reading into sections to make it easier for readers to break down the information that is being communicated and make it generally be an easier read. The sections are numbered to make this feel shorter as well so the reader feels less like this whole article is a big wall of text. Sticky headings were used and where intentionally made to stay at the top so that especially in mobile viewport have an impactful difference for users to know in which section they are at as well as following the articles description of type being locked in position in a metal frame.

## Interaction

We kep the interaction intentionally small and only on things that are clickable because the whole argument of this article is that things should not be overcomplicated without actual meaning and functional intent. We chose to add limited interaction points that follow this intent from the author.

## Build

Semantic HTML: 'header', 'main', 'article', 'section', 'footer', 'h1', and 'h2' for structure. 'Div' is only used when their is no content meaning inside of them based on the semantic guidlines set and based on feedback from professor when it was previously section class.

CSS: colors, fonts, and size scale are based off of base size, line spacing, line length.

Flexbox are used for rows and columns, and grid is use for the two-column article

Clamp() and viewport units used so the title scales smoonthly between screen sizes

Logical properties used throughout.
